# Game

A browser Game Boy player built on [EmulatorJS](https://emulatorjs.org).

No game is included — open the page and choose your own `.gb` / `.gbc` ROM. It is kept in your browser (IndexedDB) and never uploaded.

Installable as a PWA: on Android, open the page in Chrome and choose **Install app** (or **Add to Home screen**).
